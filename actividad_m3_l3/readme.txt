PROYECTO: EJERCICIOS DE CONTROL DE FLUJO EN PYTHON
===========================================================

DESCRIPCIÓN:
Este proyecto contiene una serie de ejercicios diseñados para 
practicar la lógica de programación mediante estructuras 
condicionales simples, múltiples, anidadas y de borde.

RESPUESTAS A LAS PREGUNTAS DE REFLEXIÓN:

1. ¿Qué tipo de condición te resultó más intuitiva?
   la condicion if-else es para mi la más intuitiva, 
   ya que es muy similar al pensamiento humano: 
   "Si ocurre esto, haz A; de lo contrario, haz B". Sin embargo, 
   el uso de "elif" en decisiones múltiples también es muy 
   claro para organizar jerarquías (como las calificaciones), 
   evitando llenar el código de demasiados niveles de sangría.

2. ¿En qué caso usarías condicionales anidadas en un programa real?
   Las condicionales anidadas son útiles cuando una decisión 
   depende de que se haya cumplido una condición previa. 
   
   Esto permite segmentar los errores (por ejemplo, avisar si 
   el usuario no existe antes de siquiera verificar la contraseña).
