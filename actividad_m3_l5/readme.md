Análisis de Estructuras de Datos en Python

---

### 1. ¿Cuál estructura te pareció más flexible?
Las **listas** son las más flexibles porque permiten realizar todas las operaciones de modificación dinámica (agregar, eliminar y actualizar). Su capacidad de mantener un orden mediante índices, sumado a métodos como pop() o append(), son ideales para manejar colecciones de datos que cambian constantemente.

### 2. ¿Para qué tipo de problema usarías un diccionario en lugar de una lista?
Se utiliza un **diccionario** cuando la información requiere una etiqueta o contexto para ser identificada, como en registros de usuarios o configuraciones. A diferencia de una lista, permite recuperar valores directamente mediante una "clave" única, lo que hace el código mucho más legible y eficiente cuando se manejan múltiples atributos de un mismo objeto.
