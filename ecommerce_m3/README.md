#  3D STORE — E-commerce 

Aplicación de consola desarrollada en Python que simula el comportamiento básico de un ecommerce. Permite explorar un catálogo de productos, buscarlos, agregarlos a un carrito y calcular el total de la compra.

---

## Cómo ejecutarlo

Asegúrate de tener **Python 3.10 o superior** instalado. Luego ejecuta:

```bash
python ecommerce_m3.py
```

---

## Funcionalidades

| Opción | Descripción |
|--------|-------------|
| `1` | Ver catálogo completo de productos |
| `2` | Buscar producto por nombre, categoría o ID |
| `3` | Agregar producto al carrito (por ID o nombre) |
| `4` | Ver carrito y total a pagar |
| `5` | Vaciar el carrito |
| `0` | Salir del programa |
