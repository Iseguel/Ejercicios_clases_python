


1. ¿Cuál fue la diferencia principal que notaste entre for y while?

R: La diferencia principal es que el ciclo for es ideal cuando sabemos cuántas veces queremos iterar o para recorrer colecciones fijas (como mostrar los productos del catálogo). En cambio, el while es mejor cuando no sabemos la cantidad de iteraciones y dependemos de una condición (como mantener el menú principal activo hasta que se ingrese "0").

2. ¿Te pareció útil el uso de break y continue? ¿Por qué?

R: Sí, son muy útiles para controlar los ciclos. break permite salir completamente de un ciclo al instante (ideal para detener un ciclo for apenas encontramos el producto buscado). continue permite saltar la iteración actual y pasar a la siguiente (perfecto para ignorar errores de escritura del usuario y volver a pedirle el dato sin detener el programa).
