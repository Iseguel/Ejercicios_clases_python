
#• ¿Qué te pareció más interesante o diferente respecto a cómo habías programado antes?

Me parece interesante el uso de las clases, hace que la programación sea más fácil de 
entender y abordar procesos complejos. Permiten organizar el código de manera modular, agrupando 
datos y funciones relacionadas en unidades lógicas (los objetos). Esto facilita la reutilización de código, 
lo cual es fundamental para proyectos grandes y escalables.
