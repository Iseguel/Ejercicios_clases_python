# 🛒 3D Store - Sistema de E-Commerce

## Descripción
Esta es una aplicación sencilla de consola que simula una tienda virtual. Cuenta con dos modos principales:

* **Modo Cliente:** Permite ver el catálogo, buscar productos, agregarlos al carrito de compras y generar un recibo de compra.
* **Modo Administrador:** Permite gestionar la tienda agregando, editando, eliminando y guardando los productos en el catálogo.

## Opciones del Menú

### 👤 Menú Cliente
* **1.** Ver catálogo de productos.
* **2.** Buscar producto por nombre o categoría.
* **3.** Agregar producto al carrito.
* **4.** Ver carrito y total.
* **5.** Confirmar compra.
* **6.** Vaciar carrito.
* **0.** Salir.

### 🛠️ Menú Administrador
* **1.** Ver catálogo de productos.
* **2.** Crear nuevo producto.
* **3.** Actualizar producto del catálogo.
* **4.** Eliminar producto del catálogo.
* **5.** Guardar catálogo en archivo.
* **0.** Salir.

## Cómo ejecutar el programa
1. Abre la terminal o consola de tu computadora.
2. Navega hasta la carpeta donde se encuentra descargado este proyecto.
3. Escribe el siguiente comando y presiona **Enter**:

`python ecommerce_m4.py`

*(Nota: Dependiendo de tu sistema operativo, es posible que necesites escribir `python3 ecommerce_m4.py`)*
